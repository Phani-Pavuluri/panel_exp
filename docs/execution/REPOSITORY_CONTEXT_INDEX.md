# GeoX repository context navigation

This stable index is navigation only. It intentionally contains no mutable task
ID, status, feature branch, or sibling commit pins. Current execution identity
and authority are in `docs/execution/EXECUTION_STATE.json` and
`docs/execution/ACTIVE_TASK.md`; the current result is in
`docs/execution/LATEST_COMPLETION_REPORT.md`.

Governance standards: `docs/program/LEAN_REPOSITORY_DELIVERY_STANDARD.md` and
`docs/execution/TASK_EXECUTION_STANDARD.md`. GeoX analytical ownership and
evidence are under `panel_exp/contracts/`, `tests/fixtures/`, and
`docs/track_d/`. Bootstrap requires Git synchronization, main equality, then
reading the execution files before task work.
